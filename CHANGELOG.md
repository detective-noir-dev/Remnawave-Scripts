# Changelog

## 1.9.0

### Обновления
- `rw-scripts rollback` и пункт «Откатить последнее обновление»: перед обновлением прежняя версия (скрипт, модули, словари) сохраняется в `~/.local/share/remnawave/previous`. Откат проверяет копию по её контрольным суммам и сам обратим: текущая версия становится «предыдущей».
- `rw-scripts verify [--online]` и пункт «Проверить целостность файлов»: сверка установленных файлов с `SHA256SUMS`, который теперь сохраняется при установке и обновлении. С `--online` сравнение идёт с репозиторием.
- Обновление теперь обновляет и `uninstall.sh` с `countries.csv` (раньше менялся только скрипт и словари). `install.sh` ставит проверенный `version.txt`.

### Интерфейс
- Меню стало компактнее: дашборд занимает 7 строк вместо ~20, в главном меню нет подсказок под пунктами, баннер и заголовки подменю — одна строка. Главный экран влезает в ~16 строк вместо ~40.
- Подменю «Обслуживание» без подсказок и разделителей (8 пунктов вместо 6, включая откат и проверку).

## 1.8.0

### Структура
- `scripts.sh` разрезан на модули `lib/*.sh` (по теме: firewall, hy2, warp, cleaner, memory, scanner, menus и т.д.). В `scripts.sh` остались настройки, язык, проверка хэшей и запуск (~200 строк вместо 3000).
- Модули ставятся и обновляются с проверкой SHA256, как и словари. Список модулей берётся из `SHA256SUMS`, новый файл в `lib/` подхватывается без правок кода. Если обновление пришло от старой версии без модулей, недостающее докачивается при первом запуске.
- Вместо `sudo` в каждой команде используется `$SUDO`: пустой под root, `sudo` для остальных.
- Новый `lib/pkg.sh`: один список менеджеров пакетов (apt-get, dnf, yum, pacman, zypper, apk, brew) вместо четырёх цепочек if/elif. В `install.sh` дублирующиеся цепочки тоже заменены таблицей.

### Новое
- `rw-scripts doctor [--online]`: проверка зависимостей, прав, модулей, словаря и доступности репозитория. `rw-scripts version`: печать версии.

### Качество
- CI: тесты на ubuntu 22.04/24.04, debian 12 и alpine 3.20 (alpine пока не блокирует сборку), отдельное задание ShellCheck, smoke-тест установленной раскладки.
- Юнит-тесты на bats (`tests/bats`): `iso_to_flag`, `_clean_human`, разбор вывода ufw/firewalld/iptables, `ports.json`, выбор пакетного менеджера.
- Новые проверки в `tests/run.sh`: функции не дублируются, в модулях нет кода вне функций, нет прямых вызовов `sudo`.
- Релизы: тег `vX.Y.Z` запускает `.github/workflows/release.yml` (сверка с `version.txt` и `SHA256SUMS`, заметки из этого файла).
- `SHA256SUMS` пересобирается автоматически при коммите: один раз выполните `tools/setup-hooks.sh`.

### Прочее
- Удалены `README-RU.md` (устарел) и `countries.csv.txt` (дубль `countries.csv`). Основной README: `README.md`, `README-ENG.md` — его перевод.

## 1.7.0

### Безопасность
- Самообновление (`Maintenance → Update`) и `install.sh` сверяют скачанные файлы с `SHA256SUMS`. Если хотя бы один хэш не совпал, ничего не устанавливается. `scripts.sh` заменяется последним, поэтому прерванное обновление не ломает рабочую версию.
- Если нет `sha256sum`/`shasum` или записи в `SHA256SUMS`, обновление отменяется (fail closed).

### Структура
- Словарь интерфейса вынесен из `scripts.sh` в `lang/ru.sh` и `lang/en.sh`; `scripts.sh` стал короче примерно на 370 строк.
- При обновлении со старой версии недостающий словарь докачивается автоматически с проверкой хэша.
- Новые файлы: `SHA256SUMS`, `tools/gen-checksums.sh`.

### Качество
- GitHub Actions (`.github/workflows/ci.yml`): ShellCheck и тесты на каждый push и pull request.
- `tests/run.sh`: синтаксис всех скриптов, одинаковые ключи в `ru`/`en`, наличие каждого `tr_text KEY` в словаре, актуальность `SHA256SUMS`, проверка `fetch_verified`.
- Исправлены замечания ShellCheck: незакавыченная подстановка в меню очистки, `cd -` без обработки ошибки в сканере (3 места), редирект без команды при очистке списка сканера.

### Для разработчиков
После правок `scripts.sh`, `lib/*`, `lang/*`, `uninstall.sh`, `countries.csv` или `version.txt` нужно обновить `SHA256SUMS` (`tools/gen-checksums.sh`), иначе CI упадёт, а пользователи не смогут обновиться. С версии 1.8.0 это делает хук pre-commit.
