# Установка пакетов

`_pkg_install` · `lib/pkg.sh` L42

`_pkg_install pkg…` — для каждого пакета, которого нет ни как команды, ни в `dpkg`, делает тихий `apt-get install -y` (запасной вариант — `apt`). Ошибки игнорирует. Используется в zram и сканере.

## Внешние команды и файлы
`apt-get`, `dpkg`
