# Деинсталлятор

`uninstall.sh` · файл в корне репозитория

Полностью удаляет скрипт. Вызывается из `delete_self` (`$DATA_DIR/uninstall.sh`).

## Что происходит
1. спрашивает подтверждение (y/n)
2. удаляет `~/.local/bin/rw-scripts`
3. удаляет `DATA_DIR` и `CONFIG_DIR` целиком

## Откуда вызывается
- [[Окружение]]
- [[delete_self]]
