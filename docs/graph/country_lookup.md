# Поиск страны и флага

`country_lookup` · `lib/ids.sh` L48

Ищет страну по подстроке (русское или английское название) в `countries.csv` и показывает ISO-код с эмодзи-флагом. Ввод `0` — выход. Если совпадений больше 10 — спрашивает, показывать ли все.

## Что происходит
1. читает `$DATA_DIR/countries.csv`, а при запуске из клона — `countries.csv` из корня репозитория (колонки: ru, en, iso)
2. `awk` фильтрует по ключу без учёта регистра
3. для каждого результата `iso_to_flag`

## Внешние команды и файлы
`countries.csv`
