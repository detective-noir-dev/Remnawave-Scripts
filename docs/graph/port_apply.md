# Применение правила порта

`port_apply` · `lib/firewall.sh` L393

Применяет открытие или закрытие порта без интерактивных запросов. Используется меню портов и CLI-командой `rw-scripts ports`.

## Что происходит
1. проверяет порт, протокол и наличие поддерживаемого файрвола
2. меняет правило во всех запрошенных протоколах
3. перезагружает firewalld или сохраняет правила iptables
4. только после успешного изменения файрвола обновляет `ports.json`

## Откуда вызывается
- [[open_port]]
- [[close_port]]
- `cli_ports`
