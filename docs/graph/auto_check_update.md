# Тихая проверка обновлений

`auto_check_update` · `scripts.sh` L39

Скачивает `version.txt` из репозитория (`curl -f`, таймаут 5 с, поэтому 404 или офлайн не дают ложного уведомления) и, если версия отличается от `$VERSION`, печатает жёлтое предупреждение с подсказкой «[4] Maintenance → [1] Update». Ничего не устанавливает. Вызывается один раз за сессию из `show_main_menu`.

## Внешние команды и файлы
`curl`, `REPO_URL/version.txt`

## Откуда вызывается
- [[show_main_menu]]
