# Отключение входа по паролю SSH

`disable_ssh_password_auth` · `lib/server.sh`

Отключает парольный и интерактивный парольный вход SSH. Перед изменением проверяет, что в `authorized_keys` текущего пользователя (или пользователя, вызвавшего `sudo`) есть хотя бы один распознаваемый публичный ключ: ed25519, RSA, DSA, ECDSA либо security-key. Поэтому сначала можно импортировать ключ через [[add_ssh_ed25519_key]].

Если эффективная конфигурация уже отключает оба способа входа (`sshd -T`), сообщает об этом и завершает работу без изменений. Когда `PasswordAuthentication` уже равен `no`, а `KbdInteractiveAuthentication` ещё включён, объясняет это и продолжает настройку: keyboard-interactive может принимать пароль через PAM.

## Что происходит
1. выводит предупреждение и запрашивает подтверждение;
2. создаёт резервную копию `/etc/ssh/sshd_config`;
3. устанавливает `PasswordAuthentication no`, `KbdInteractiveAuthentication no` и `ChallengeResponseAuthentication no`;
4. проверяет синтаксис и эффективные параметры командой `sshd -t`/`sshd -T`;
5. перезапускает SSH; при любой ошибке восстанавливает резервную копию и перезапускает прежнюю конфигурацию.

## Внешние команды и файлы
`/etc/ssh/sshd_config`, `sshd`, `systemctl`
