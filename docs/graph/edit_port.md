# Редактировать описание порта

`edit_port` · `lib/firewall.sh` L237

Меняет описание уже записанного порта.

## Что происходит
1. синхронизация и показ списка
2. ввод порта и протокола
3. поиск записи в `ports.json`; нет — «Порт не найден»
4. показ текущего описания, ввод нового
5. `edit_port_description`

## Использует (общие хелперы)
`ensure_jq`

## Вызывает
- [[edit_port_description]] — Запись нового описания

## Откуда вызывается
- [[port_management]]
