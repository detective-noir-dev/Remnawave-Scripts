# Файлы и каталоги вокруг скрипта

Не функция, а карта того, что лежит вокруг `scripts.sh`.

- `~/.local/bin/rw-scripts` — установленный скрипт (`SCRIPT_PATH`)
- `~/.config/remnawave/lang.conf` — язык (`ru`/`en`), читается в `LANG_SET`
- `~/.local/share/remnawave/` (`DATA_DIR`): `version.txt`, `countries.csv`, `uninstall.sh`, `ports.json`
- `/opt/RealityTLScanner/` — сканер Reality (`SCANNER_DIR`)
- `/etc/hysteria/config.yaml` — конфиг Hysteria2
- `/opt/remnanode/docker-compose.yml` — compose ноды Remnawave
- `REPO_URL` — raw GitHub репозитория (источник обновлений)
