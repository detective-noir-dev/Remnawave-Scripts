# Запуск htop

`launch_htop` · `lib/system.sh` L62

Запускает `htop`. Если его нет — предлагает установить (y/n) под спиннером через найденный пакетный менеджер; при отказе возвращается в меню.

## Использует (общие хелперы)
`loading_bar`

## Внешние команды и файлы
`htop`
