# Подробный статус памяти

`_mem_show_status` · `lib/memory.sh` L20

Экран с таблицей RAM (всего / используется / кэш / свободно) и swap (тип, выделено, используется, свободно). Если swap выключен — рекомендует включить ZRAM.

## Внешние команды и файлы
`free`, `lsblk`
