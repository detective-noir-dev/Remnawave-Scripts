# Брайль-крутилка

`loading_bar` · `scripts.sh` L56

Бесконечный спиннер из брайлевских символов с надписью «Пожалуйста, подождите». Запускается в фоне (`loading_bar & pid=$!`), прячет курсор (`tput civis`). Вызывающий обязан сделать `kill $pid; wait; tput cnorm`.
