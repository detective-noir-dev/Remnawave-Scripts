# Карта rw-scripts

Граф структуры `scripts.sh` (v1.12.8). Одна заметка — одна функция; ссылки — это **дерево меню**, а не все вызовы подряд.

**Начни отсюда:** [[show_main_menu]]

## Как читать граф
| Цвет | Тег | Что это |
|---|---|---|
| 🔴 красный | `#rw-root` | главное меню |
| 🟠 оранжевый | `#rw-menu` | меню и подменю |
| 🟢 зелёный | `#rw-func` | действие (пункт меню) |
| 🔵 синий | `#rw-helper` | внутренняя функция конкретной ветки |
| 🟣 фиолетовый | `#rw-shared` | общий хелпер (используется везде) |
| ⚪ серый | `#rw-hub`, `#rw-file` | группы и файлы репозитория |

Общие функции (`tr_text`, `show_banner`, `detect_firewall`, `ensure_jq` …) собраны в [[Общие хелперы]], чтобы не рисовать сотни линий. В каждой заметке их список — в разделе «Использует».

## Ветки
1. [[submenu_id_flags]] — Short ID и флаги
2. [[submenu_monitor]] — мониторинг ресурсов
3. [[submenu_network]] — порты и файрвол
4. [[submenu_maintenance]] — обновление, очистка, память, сканер, удаление
5. [[submenu_server]] — SSH, Zapret, Hysteria2, WARP, **Dante SOCKS5**
   - 5.5 [[submenu_dante]] — SOCKS5-прокси Dante (IP whitelist, фаервол, статус)
6. [[submenu_thirdparty]] — сторонние скрипты
