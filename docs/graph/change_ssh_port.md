# Смена SSH-порта

`change_ssh_port` · `scripts.sh` L1232

Безопасно меняет порт SSH-сервера и открывает его в файрволе.

## Что происходит
1. читает текущий `Port` из `/etc/ssh/sshd_config` (по умолчанию 22)
2. предупреждение о риске потерять доступ
3. ввод нового порта (1024–65535) и подтверждение
4. правит `Port` через `sed` (обычная строка, закомментированная или добавление в конец)
5. открывает порт в ufw/firewalld/iptables
6. `systemctl restart sshd` (или `ssh`)
7. печатает команду `ssh -p <порт> user@<ip>`

## Использует (общие хелперы)
`detect_firewall`

## Внешние команды и файлы
`/etc/ssh/sshd_config`, `systemctl`
