# Смена SSH-порта

`change_ssh_port` · `lib/server.sh` L6

Безопасно меняет порт SSH-сервера и открывает его в файрволе.

## Что происходит
1. читает текущий `Port` из `/etc/ssh/sshd_config` (по умолчанию 22)
2. предупреждение о риске потерять доступ
3. ввод нового порта (1024–65535) и подтверждение
4. создаёт резервную копию, правит `Port` через `sed` (обычная строка, закомментированная или добавление в конец) и проверяет конфиг через `sshd -t`
5. открывает порт в ufw/firewalld/iptables; при ошибке возвращает прежний конфиг
6. [[_ssh_restart_service]], затем проверяет через `ss`, что новый порт слушается; при ошибке восстанавливает прежний конфиг и перезапускает SSH
   - в iptables правило вставляется в начало цепочки (`-I`)
7. печатает команду `ssh -p <порт> user@<ip>`

`detect_firewall`

## Внешние команды и файлы
`/etc/ssh/sshd_config`, `systemctl`
