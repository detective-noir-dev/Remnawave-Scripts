# Главное меню

`show_main_menu` · `lib/menus.sh` L203

Точка входа. Бесконечный цикл: перерисовывает дашборд, один раз за сессию тихо проверяет обновления, печатает 6 групп — каждая с серой подсказкой (`HINT_*` из словаря) — и по `case` передаёт управление в подменю. Пункт 0 завершает скрипт (`exit 0`). Во всех меню конец ввода (EOF) тоже завершает скрипт. Вызывается последней строкой файла (`# ЗАПУСК`).

Вспомогательная функция `_mi num label hint` выводит пункт + серую подпись через `${DIM}…${NC}`.

## Что происходит
1. `show_dashboard` — шапка с системной информацией
2. при первом проходе (`_UPDATE_CHECKED=0`) — `auto_check_update`
3. вывод пунктов 1–6 и 0
4. `read` выбора → `submenu_*`
