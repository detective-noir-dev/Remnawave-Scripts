# Пользователь SSH-настроек

`_ssh_target_user` · `lib/server.sh` L132

Возвращает пользователя, для которого применяются настройки SSH: сначала `$SUDO_USER`, затем `$USER`, в последнюю очередь результат `id -un`. Это позволяет добавлять ключ и проверять `authorized_keys` у пользователя, который запустил скрипт через `sudo`.
