# Команда под крутилкой

`_run_spinner` · `scripts.sh` L1922

Запускает любую команду (`"$@"`) под `loading_bar`, пишет её вывод во временный лог. Если команда упала — показывает последние 15 строк лога. Возвращает код возврата команды. Используется в `install_warp`.

## Что происходит
1. `mktemp` лог → `loading_bar &`
2. выполнить `"$@"`
3. остановить спиннер, `tput cnorm`
4. при `rc≠0` — `tail -n 15 $log`
