# Инспектор каталога

`_disk_inspector` · `lib/cleaner.sh` L107

Рекурсивный обзор каталога: топ-15 крупнейших элементов (`du -sh | sort -hr`). Выбор каталога — заходит внутрь (рекурсия), выбор файла — показывает последние 50 строк или удаляет. Режимы: `block` — только просмотр (красное предупреждение), `truncate` — очищает файл (`sudo truncate`), `rm` — удаляет (`sudo rm`). Чтение и размеры через `sudo`; результат честный: ошибка прав не выдаётся за успех.

## Внешние команды и файлы
`du`, `tail`
