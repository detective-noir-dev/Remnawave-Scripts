# Очистка Docker

`_do_clean_docker` · `lib/cleaner.sh` L63

Перед `docker system prune -a --volumes -f` предупреждает, что будут удалены все неиспользуемые образы, контейнеры, сети и тома, и ждёт подтверждения. В неинтерактивном запуске Docker пропускается. Если Docker не установлен — сообщение и выход.

## Внешние команды и файлы
`docker`
