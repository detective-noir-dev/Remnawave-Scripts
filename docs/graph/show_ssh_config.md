# Просмотр конфигурации SSH

`show_ssh_config` · `lib/server.sh` L140

Выводит содержимое `/etc/ssh/sshd_config` в терминал. Чтение выполняется через `$SUDO`, чтобы конфигурацию можно было просмотреть и при ограниченных правах пользователя. После вывода ждёт Enter.
