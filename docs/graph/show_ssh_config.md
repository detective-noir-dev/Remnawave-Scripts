# Редактирование конфигурации SSH

`show_ssh_config` · `lib/server.sh` L140

Открывает `/etc/ssh/sshd_config` в `$SUDO_EDITOR`, `$VISUAL`, `$EDITOR` или первом доступном редакторе из `nano`, `vim`, `vi`. До редактирования создаёт резервную копию; затем проверяет конфиг через `sshd -t` и перезапускает SSH. При ошибке редактора, проверке или перезапуске восстанавливает прежний файл.
