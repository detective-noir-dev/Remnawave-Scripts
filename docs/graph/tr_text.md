# Словарь RU/EN

`tr_text` · `lang/ru.sh`, `lang/en.sh`

`tr_text KEY` возвращает строку интерфейса по ключу. Словарь вынесен из `scripts.sh` в `lang/ru.sh` и `lang/en.sh` (в каждом свой `tr_text` с `case`). `load_lang` в `scripts.sh` подключает нужный файл по `LANG_SET`: сначала `lang/` рядом со скриптом (клон репозитория), затем `$DATA_DIR/lang/`; если файла нет, докачивает его с проверкой SHA256. Ключи в обоих файлах должны совпадать — это проверяет `tests/run.sh`.
