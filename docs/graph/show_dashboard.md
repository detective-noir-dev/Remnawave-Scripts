# Системный дашборд

`show_dashboard` · `lib/menus.sh` L77

Шапка главного меню. Собирает и рисует сводку о сервере. Медленные сетевые данные (внешний IP, ping, тип виртуализации) кэшируются в переменные `_DASH_*` на всю сессию. Внутри определена вложенная `_pbar` — цветной прогресс-бар (зелёный <70%, жёлтый ≥70%, красный ≥90%).

## Что происходит
1. ОС/ядро (`/etc/os-release`, `uname -r`), аптайм (`uptime -p`), число сессий (`who`)
2. виртуализация (`systemd-detect-virt`: KVM/LXC/OpenVZ/физика)
3. CPU: модель из `/proc/cpuinfo`, ядра `nproc`, загрузка = loadavg/ядра
4. RAM из `free -m`, диск `/` из `df`, тип диска HDD/SSD/NVMe (`rotational`)
5. внешний IP (`ifconfig.me` → `api.ipify.org` → `hostname -I`) и `ping 8.8.8.8` — один раз
6. язык и версия, отрисовка трёх блоков СИСТЕМА / ЖЕЛЕЗО / СТАТУС

## Внешние команды и файлы
`/proc`, `free`, `df`, `curl`, `ping`, `systemd-detect-virt`
