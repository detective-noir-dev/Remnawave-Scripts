# Добавление публичного ключа SSH ed25519

`add_ssh_ed25519_key` · `lib/server.sh`

Запрашивает одну строку публичного ключа `ssh-ed25519` и проверяет её синтаксис. Если точно такой же ключ уже есть в `authorized_keys`, сообщает об этом и не меняет файл. Если там есть другие ключи `ed25519`, показывает их количество и запрашивает подтверждение замены; при согласии заменяет все ключи этого типа, сохраняя остальные строки. Отказ оставляет файл без изменений. Для `.ssh` и `authorized_keys` устанавливаются права `700` и `600`.

## Внешние команды и файлы
`getent`, `ssh-keygen`, `install`, `/home/<пользователь>/.ssh/authorized_keys`
