# Добавление публичного ключа SSH ed25519

`add_ssh_ed25519_key` · `lib/server.sh` L140

Запрашивает одну строку публичного ключа `ssh-ed25519`, проверяет её синтаксис через `awk` и `ssh-keygen -lf -`, затем добавляет ключ в `~/.ssh/authorized_keys` текущего пользователя (или пользователя, вызвавшего `sudo`). Дубликат не добавляется. Для `.ssh` и `authorized_keys` устанавливаются безопасные права `700` и `600`.

## Внешние команды и файлы
`getent`, `ssh-keygen`, `install`, `/home/<пользователь>/.ssh/authorized_keys`
