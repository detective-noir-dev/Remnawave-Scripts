Remnawave-Scripts — Bash-скрипт с интерактивным меню для настройки и обслуживания Linux-сервера, в том числе ноды Remnawave: SSH, порты и файрвол, Hysteria2, Cloudflare WARP, SOCKS5-прокси, очистка, swap и поиск доменов для Reality. Интерфейс на русском и английском.

## 🚀 Установка

```bash
bash <(curl -s https://raw.githubusercontent.com/detective-noir-dev/Remnawave-Scripts/main/install.sh)
```

Запуск:

```bash
rw-scripts
```

При первой установке скрипт спросит язык. Если `~/.local/bin` не было в `PATH`, откройте новый терминал после установки.

**Обновление:** пункт `4 → 1` в меню. Перед обновлением прежняя версия сохраняется, вернуться к ней можно пунктом `4 → 6` или командой `rw-scripts rollback`.

## 📌 Возможности

### 🆔 Short ID и флаги стран
- Генерация любого количества `shorts_id` (16 hex-символов).
- Поиск страны по части названия на русском или английском.

### 🔐 Сеть и порты
- Поддерживаются **UFW**, **FirewallD** и **iptables**.
- Открытие и закрытие TCP, UDP или обоих протоколов.
- Список портов синхронизируется с файрволом, описания хранятся в `~/.local/share/remnawave/ports.json`.

### 🖥️ Настройка сервера

| Пункт | Что делает |
|-------|------------|
| 🔑 Сменить SSH порт | Порт 1024–65535: правит конфиг, открывает порт в файрволе, перезапускает SSH; при ошибке возвращает прежний конфиг |
| 🔐 Добавить ключ ed25519 | Проверяет ключ и добавляет в `authorized_keys`; замена других ключей ed25519 — только после подтверждения |
| 🚫 Отключить вход по паролю | Требует уже добавленный SSH-ключ; проверяет конфиг и откатывает изменения при ошибке |
| 📝 Редактировать конфиг SSH | Открывает `sshd_config` в редакторе и проверяет его перед перезапуском SSH |
| 🛡️ zapret | Запускает сторонний установщик |
| ⚡ Hysteria2 | Установка, удаление, конфиг, сервис, логи, версия, обновление; настройка для Remnanode |
| ☁️ Cloudflare WARP | Установка, статус, включение, отключение, удаление |
| 🧦 Dante | SOCKS5-прокси: установка, список разрешённых IP, статус, перезапуск, логи, удаление |

> ⚠️ Перед изменением настроек SSH не закрывайте текущую сессию и проверьте вход во второй.

**Hysteria2 для Remnanode** настраивает Xray-инбаунд: добавляет сертификат Let's Encrypt в `docker-compose.yml`, создаёт хук перезапуска после продления сертификата и открывает UDP-порт. Нужны root, файл `/opt/remnanode/docker-compose.yml` и уже выпущенный сертификат.

**Cloudflare WARP** ставится в режиме SOCKS5-прокси на `127.0.0.1:<порт>` (по умолчанию 40000). Нужны Ubuntu или Debian и права root. Использование: `export ALL_PROXY=socks5://127.0.0.1:<порт>`.

**Dante** пускает только перечисленные IP-адреса (порт по умолчанию 1080). Пароля у прокси нет, а SOCKS5 сам по себе не шифрует трафик. Если у сервера сменился IP, перезапустите сервис: статус подскажет, когда это нужно.

### 🧹 Очистка системы (`4 → 3`)
- Всё сразу или по категориям: APT, journald, Docker, временные файлы, старые версии Snap.
- Показывает, сколько места освободилось.
- Анализатор диска: просмотр крупных файлов; в `/var/log` их можно очистить, в кэше APT и `/tmp` — удалить.

> ⚠️ Полная уборка обнуляет файлы логов в `/var/log` и логи Docker-контейнеров, а также удаляет всё содержимое `/tmp`, `/var/tmp` и `~/.cache`. Очистка Docker удаляет неиспользуемые образы, контейнеры, сети и **тома**, поэтому спрашивает отдельное подтверждение.

### 🧠 Память и Swap (`4 → 4`)
- Гибридный режим (ZRAM и swap-файл на диске), только ZRAM или только swap.
- Рекомендации по объёму RAM, подробный статус, примеры лимитов памяти для Docker.
- Режимы «только ZRAM», «только swap» и отключение удаляют прежний `/swapfile`.

### 🔍 Reality TLS Scanner (`4 → 5`)
- Поиск SNI-доменов для VLESS+Reality: одна цель или список целей.
- Сортировка результатов по издателю сертификата, отчёты в CSV.
- Сам ставит Go, собирает [RealiTLScanner](https://github.com/XTLS/RealiTLScanner) и скачивает GeoIP-базу.

### 🔧 Сторонние скрипты
- **Remnawave (EGames)** — reverse-proxy решение от eGamesAPI.
- **Reshala** — скрипт от DonMatteoVPN.
- **Multitest** — утилита от saveksme, ставится в `/usr/local/bin/multitest`.

После установки может понадобиться новый терминал или `source ~/.bashrc`.

## ⌨️ Команды без меню

Для cron, мониторинга, CI и баг-репортов:

```bash
rw-scripts help               # список команд
rw-scripts status             # состояние установленных сервисов
rw-scripts ports              # открытые порты
rw-scripts ports open 443/tcp # открыть порт; без /tcp или /udp — оба протокола
rw-scripts ports close 443/tcp
rw-scripts warp status        # или connect / disconnect
rw-scripts hy2 restart        # или status / start / stop / enable / logs / version
rw-scripts clean              # полная очистка; в терминале спросит только про Docker, из cron Docker пропускается
rw-scripts doctor [--online]  # диагностика зависимостей, прав, модулей и доступа к репозиторию
rw-scripts rollback [--yes]   # вернуться на версию до последнего обновления
rw-scripts config set lang en # настройки: lang (ru|en), color (auto|always|never)
rw-scripts log 20             # последние строки журнала действий
rw-scripts completion bash    # автодополнение (bash или zsh); bash-вариант ставит установщик
rw-scripts version            # версия
```

Цвета отключаются переменной `NO_COLOR`, а при выводе не в терминал — автоматически.

## 🔐 Безопасность

- **Права:** изменения системы требуют root или `sudo`.
- **Сторонние скрипты** (zapret, Hysteria2, eGames, Reshala, Multitest) сначала скачиваются во временный файл. Скрипт показывает размер и SHA256 и спрашивает подтверждение (`v` — посмотреть содержимое). Копия сохраняется в `~/.local/share/remnawave/third-party/`. Это чужой код: проверяйте его перед запуском.
- **Порты:** открывайте только нужные — изменения сразу применяются к системному файрволу.
- **Обновление пакетов** (`4 → 2`) не задаёт вопросов по ходу установки: изменённые вами конфиги сохраняются.

## 📦 Системные требования

- **ОС:** Linux. Основная цель — Ubuntu и Debian с systemd. Управление памятью, обновление пакетов и WARP рассчитаны на системы с `apt`; другие функции на прочих системах могут работать не полностью.
- **Нужны:** `bash`, `curl`.
- **Ставятся по мере необходимости:** `jq` (порты), `xxd` (генерация ID), `htop` и `neofetch` (монитор).
- **Для управления портами:** `ufw`, `firewalld` или `iptables`.

CI проверяет скрипт на Ubuntu 22.04 и 24.04, Debian 12 и Alpine 3.20 (проверка на Alpine не блокирует сборку).

## ⚙️ Удаление

В меню: пункт `4 → 7`. Или напрямую:

```bash
~/.local/share/remnawave/uninstall.sh
```

Удаляются сам скрипт, его данные и настройки. То, что вы установили или изменили через него на сервере (Hysteria2, WARP, настройки SSH и файрвола), остаётся.

## 🌍 Язык

Русский и английский. Выбирается при первой установке и хранится в `~/.config/remnawave/config`. Сменить: `rw-scripts config set lang ru` (или `en`).

## 🛠️ Структура репозитория

- **scripts.sh** — ядро: настройки, язык, загрузка модулей, запуск
- **lib/** — модули по темам: `menus.sh` (меню и дашборд), `server.sh` (SSH, zapret), `firewall.sh`, `hy2.sh`, `warp.sh`, `dante.sh`, `cleaner.sh`, `memory.sh`, `scanner.sh`, `maintenance.sh`, `thirdparty.sh`, `system.sh`, `ids.sh`, `cli.sh` (команды без меню), `doctor.sh`, `common.sh`, `pkg.sh`
- **lang/** — словари интерфейса (`ru.sh`, `en.sh`)
- **docs/graph/** — карта функций в формате Obsidian
- **tests/**, **tools/**, **.githooks/** — тесты (`bash tests/run.sh`, bats в `tests/bats`), служебные скрипты и хуки git
- **install.sh**, **uninstall.sh** — установка и удаление
- **countries.csv** — база стран (RU/EN и ISO-код)
- **version.txt**, **CHANGELOG.md** — версия и история изменений
- **SHA256SUMS** — контрольные суммы для обновления со старых версий
- **README.md** — основной файл, **README-ENG.md** — его перевод
